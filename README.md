A server side mod for making life on servers easier.
Sometimes people want to have keepinv on, and other dont. Why bother and lets just give then a choice!
Commands featured in mod:
--
##  Base 
### Main commands
### /keepinv status
- shows current status of keep Inventory of player

### /keepinv enabled [true/false]
- changes current keep Inventory status of player

### /keepinv pvpSafe [true/false]
- changes if your inventory will be saved after death in fight with other player (might get config to be toggleable on server)

## Duels
### Enables forced keep inventory for both players

### /duel [name] 
- sends duel request to a person (also works as accept)
### /duel deny
- declines duel request.
